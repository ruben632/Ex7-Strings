# Ex7 - Strings

Cuestionario de Java realizado por Rubén y Aitor.

## Requisitos

- Un mínimo de 50 preguntas sobre Java.
- Cuatro opciones por pregunta: a, b, c y d.
- Una única respuesta correcta por pregunta.
- Introducir la respuesta desde la consola.
- Mostrar si la respuesta es correcta o incorrecta.
- Indicar la opción correcta cuando el usuario falla.
- Terminar el programa si se introduce un valor distinto de a, b, c o d.
- Utilizar String y sentencias condicionales.

## Archivos

- Ejercicio07.java muestra las preguntas, lee las respuestas y las comprueba.
- Preguntas.java guarda las 50 preguntas con sus opciones y respuestas correctas.

## Cómo ejecutarlo

1. Abrir el proyecto en IntelliJ IDEA con un JDK configurado.
2. Abrir src/Ejercicio07.java.
3. Ejecutar el método main.
4. Responder en la consola con a, b, c o d en minúscula.

Si la respuesta es correcta o incorrecta, continúa con la siguiente pregunta. Si no es válida, el programa termina.
